Python workflow tidal.workflows 
from tidal.workflows import qpruner_compress, rankadaptor_adapt

quant_run = qpruner_compress(
    model=pruned_model,
    calibration_batches=calibration_batches,
    candidate_bits=(2, 4, 8),
    max_average_bits=4.0,
)

adapter_run = rankadaptor_adapt(
    model=quant_run.model,
    sensitivities="sensitivities.json",
    budget=4096,
    max_rank=16,
)

adapter_run.save("runs/rankadaptor")

Quickstart

Install, run a workflow, keep the method package when you need internals.

Install 
git clone --recurse-submodules https://github.com/manlenzzz/tidal-ai
cd tidal-ai
python -m pip install -e ".[torch]"
CLI 
tidal compress qpruner \
  --model-id hf-internal-testing/tiny-random-LlamaForCausalLM \
  --calibration-data calibration.txt \
  --candidate-bits 2,4,8 \
  --max-average-bits 4.0

Workflows

Task-first APIs for the paths people actually run.

TIDAL keeps paper-level algorithms in method packages, then exposes stable workflow entry points for model-level experiments and engineering use.

Compression

Pruned and compressed LLMs

CAP handles global rank-sparsity allocation. QPruner handles mixed-precision decisions after structured pruning.

cap_compress, qpruner_compress
Adaptation

Rank-adaptive LoRA recovery

RankAdaptor allocates LoRA ranks under a budget and returns a PEFT-ready adapted model plus a reproducible summary.

rankadaptor_adapt
Serving

Multi-tenant LoRA serving

Dynamic operator optimization components are integrated as upstream code for serving-oriented experimentation.

tidal.methods.dynamic_operator_optimization
Growing scope

Fine-tuning, post-training, RL

The project layout leaves room for additional efficient inference, post-training, and reinforcement learning modules.

tidal.methods.*

Method registry

One toolkit surface, separate method boundaries.

Use workflows for normal experiments. Drop into `tidal.methods.*` when you need the paper algorithm, search space, or integration code directly.
