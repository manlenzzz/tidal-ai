Quickstart

Install once, import each method as a package.

git clone --recurse-submodules https://github.com/manlenzzz/tidal-ai
cd tidal-ai
python -m pip install -e ".[torch]"

Method registry

Reusable components for efficient training, compression, and serving.

Each method has its own package boundary, example entry point, and citation so downstream users can adopt one algorithm without absorbing the whole repository.

Toolkit shape

Method-first layout, shared engineering surface.

Research methods

Paper algorithms live in isolated packages.

Rank allocation, probabilistic precision search, compression, mixed-precision adaptation, and serving operators are separated by method boundary.

Shared tooling

Examples and tests expose common workflows.

Method packages are paired with focused examples so users can inspect the algorithm path before connecting full model or dataset pipelines.

Future scope

Built to grow beyond the initial papers.

The project structure leaves room for efficient inference, serving, post-training, and reinforcement learning components.
