# Redesign Project Homepage

## Why
The current TIDAL homepage reads like a heavy promotional archive and does not match the scan-friendly structure used by mature open-source toolkits. Users should immediately understand what the toolkit does, how to install it, which workflows are available, and how to cite the toolkit and method papers.

## What Changes
- Rebuild the static homepage around a clear toolkit-first hero, quickstart code, workflow cards, method matrix, citations, and team section.
- Make the visual style closer to high-star engineering repositories: white background, crisp borders, compact cards, visible code examples, and reduced decorative weight.
- Keep citations visible on the homepage while avoiding a private-paper-archive tone.
- Keep the root `index.html` and `site/index.html` aligned for GitHub Pages and local preview.

## Impact
- Static site files only.
- No algorithm, package API, citation content, or test behavior changes.
