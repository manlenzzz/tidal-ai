# Design

## Structure
The homepage will use a GitHub-toolkit style information path: top navigation, concise hero with live-looking API/CLI code, install commands, workflow cards, method matrix, citation blocks, and team attribution.

## Visual Direction
Use a restrained white/light interface with thin borders, dark readable text, teal and blue accents, small badges, and compact cards. Avoid the current dark full-bleed hero, oversized decorative layout, and vague system-map language.

## Responsive Behavior
Desktop uses two-column hero and card grids. Tablet and mobile collapse to single-column flow, hide nonessential nav items, preserve readable code blocks, and avoid text overlap.

## Verification
Validate HTML shape with lightweight parsing, run CSS/HTML smoke checks, serve the page locally, and capture desktop/mobile screenshots.
