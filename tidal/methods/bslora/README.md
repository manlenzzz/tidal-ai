# BSLoRA

BSLoRA is integrated as a team-maintained upstream method repository under
`external/BSLoRA`.

The upstream contains ShareLoRA-style PEFT extensions, pruning/evaluation
utilities, and training scripts. TIDAL keeps it as a method-scoped integration
point so the original experiment code remains available while future toolkit
APIs can wrap the reusable components.

Primary upstream package:

- `peft.tuners.share_lora`

Local upstream path:

- `external/BSLoRA`

Upstream repository:

- `https://github.com/yuhua-zhou/BSLoRA`
