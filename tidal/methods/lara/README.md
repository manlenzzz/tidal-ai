# LaRA

LaRA is integrated as a team-maintained upstream method repository under
`external/LaRA`.

The upstream contains performance-prediction, NAS/policy-network, dataset, and
inference scripts for rank-allocation research. TIDAL keeps it as a
method-scoped integration point so the original experiment code remains
available while future toolkit APIs can wrap the reusable components.

Primary upstream package:

- `model`

Local upstream path:

- `external/LaRA`

Upstream repository:

- `https://github.com/yuhua-zhou/LaRA`
