Modules

Research methods exposed as Torch-ready APIs

RankAdaptor

Performance-model rank search

Fit an MLP performance model, run online rank search, and export PEFT configs.

QPruner

MI-guided precision search

Collect layer-output mutual information and rewrite Linear layers with mixed precision.

CAP

Global rank and sparsity

Run RPCA, optimize one global rank/sparse budget, and pack Linear layers for inference.

Serving

Segmented LoRA operators

Reference SGMV and LoRA SGMV semantics for validating multi-tenant serving kernels.

Method map

Efficient training, compression, and serving in one codebase

RankAdaptorImplemented locally: MLP performance model, online incremental rank search, PEFT LoraConfig export.
QPrunerImplemented locally: calibration MI collection, budgeted bitwidth search, PyTorch quantized Linear backend.
CAPImplemented locally: RPCA, cross-layer Bernoulli rank/sparse search, PyTorch packed Linear backend.
DopIntegrated upstream repository for multi-tenant LoRA operator serving.
QR-AdaptorIntegrated upstream repository for linguistic-hierarchy mixed-precision tuning.
AutoQRAIntegrated upstream repository for joint quantization and adapter optimization.
